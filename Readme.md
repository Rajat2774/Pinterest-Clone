# Pinterest Clone

A Pinterest-inspired web application built to learn and practice **backend development with Node.js and Express.js**.

### 🚀 Tech Stack

* Node.js
* Express.js
* MongoDB
* EJS
* JavaScript

### 📌 Features

* User authentication
* Create and manage pins
* Image uploads
* User profiles
* Like/save functionality
* Basic Pinterest-style feed

### 🎯 Purpose

This project was built primarily as a **backend learning project**, focusing on REST APIs, authentication, database operations, middleware, routing, and server-side application architecture.

### ⚙️ Run Locally

```bash
npm install
npm start
```

Create a `.env` file with the required environment variables before starting the application.
